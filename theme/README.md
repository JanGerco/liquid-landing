# Liquid Landing (theme folder)

See the repository README for the overview. Quick map:

| What | File |
|---|---|
| Copy, RO + EN | `inc/i18n.php` |
| Portfolio list | `inc/portfolio.php` (section renders only when non-empty) |
| Contact form handler | `inc/contact.php` (sends to the admin email) |
| Page markup | `front-page.php`, `header.php`, `footer.php` |
| Styles | `assets/css/tokens.css` → `assets/css/theme.css` |
| Script | `assets/js/main.js` |
| Shapes and mark | `assets/img/` |
